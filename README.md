# Agent Studio Web

个人使用的智能体工作台，React + TypeScript + React Flow + Vite。基于同仓库 `deliverables/agent-studio` 的 M3E 设计实现。

## 使用

```sh
./start.sh
```

打开 http://127.0.0.1:4173 。服务器只监听本机；终端 `Ctrl+C` 停止。脚本前台运行，不安装开机启动、守护进程或定时器。这个应用独立于 M3E Canvas，启动它不会启动 M3E。

推荐体验：点击核验员 → 编辑脚手架 → 调整模型或证据策略 → 返回画布；打开 Trace 的基线记录 → 选“引用缺少证据” → 查看评价与回归用例 → 创建修复草稿。

## 已实现

- 真实节点拖拽、端口连线、框选、方向键移动、缩放、平移、小地图、节点/连线详情、删除撤销、键盘连线表单。
- 单智能体/团队模板；要件表单；9 类成员配置与能力匹配的模型参数；资源目录。
- 本地草稿备份、不可变配置快照、JSON 导出/恢复；切换配置前保留尚未保存的草稿。
- 模拟播放，含人工批准/拒绝、取消、预算、循环、超时与不完整 Trace。
- Trace 输入输出和配置快照；Code/LLM 模拟评价及真实本地人工批注。
- 固定数据集版本比较、本地扩展用例集及默认版本确认。

## 边界

**只有前端。** 没有真实 Agent 执行引擎、数据库、模型调用、MCP 服务、检索服务、OTLP Collector 或真实批量评测。所有运行、指标、机器评分都是标明的模拟数据。自定义输入/改动配置的模拟播放不会获得预置版本的质量成绩。并行/工具等新节点可以编排和保存，其执行语义未实现；尚无子流程折叠。

数据保存在当前浏览器、当前访问地址的 localStorage。换浏览器、换端口或清除站点数据不会共享配置，请使用“本地备份”导出。浏览器存储损坏时保留原始数据供导出；存储不可用时不宣称已保存。配置中不存放密钥。

页面关闭或离开试运行会停止模拟播放器，不在后台继续任务。旧运行始终保留自己的快照；设为默认不发布、不执行、不修改当前草稿。

## 开发与验证

使用现有 Node.js 24（`/opt/homebrew/opt/node@24/bin`），未改动系统默认版本。

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

生产静态文件在 `dist/client`。依赖固定在 `package-lock.json`。保留 starter 的可选 Sites 构建文件，但没有部署网站。

浏览器验收与截图记录：`design-qa.md`、`qa/`。自动测试验证配置快照、本地恢复、输入校验、模拟来源匹配等数据边界。
